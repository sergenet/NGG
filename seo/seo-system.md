## Internal Linking Rules

### Silo Structure Rules
1. **Vertical links (parent ↔ child):** Every article MUST link up to its parent category page, and every category page MUST link down to its child articles
2. **Horizontal links (sibling ↔ sibling):** Articles within the same silo SHOULD link to 2–3 sibling articles
3. **Cross-silo links:** Use SPARINGLY — only when contextually relevant (e.g., "If you're upgrading your kitchen AND home office, check our [standing desk guide]")
4. **Homepage links:** Feature top 3 articles per category on the homepage

### Linking Density
- **Target:** 2–4 internal links per 1,000 words
- **Anchor text:** Use descriptive, natural anchors (avoid "click here" or exact-match keywords)
- **Placement:** Primarily in-content; supplement with "Related Articles" sections

### Required Links per Page
- **Every page:** Link to its parent category + 2 related articles
- **Category pages:** Link to ALL child articles + homepage
- **Homepage:** Link to all 3 category pages + top 6 articles

## Schema Markup Recommendations

### Homepage — WebSite
```json
{
  "@context": "https://schema.org",
  "@type": "WebSite",
  "name": "NewGiftsAndGadgets",
  "url": "https://newgiftsandgadgets.com/"
}
```

### Category Pages — CollectionPage
```json
{
  "@context": "https://schema.org",
  "@type": "CollectionPage",
  "name": "[Category Name]",
  "url": "https://newgiftsandgadgets.com/[category]/"
}
```

### Roundup Posts — ItemList
```json
{
  "@context": "https://schema.org",
  "@type": "ItemList",
  "name": "[Number] Best [Product]",
  "itemListElement": [
    { "@type": "ListItem", "position": 1, "item": { "@type": "Product", "name": "[Name]" } }
  ]
}
```

### Single Reviews — Product + Review
```json
{
  "@context": "https://schema.org",
  "@type": "Product",
  "name": "[Product Name]",
  "review": {
    "@type": "Review",
    "reviewRating": { "@type": "Rating", "ratingValue": "4.8", "bestRating": "5" },
    "author": { "@type": "Person", "name": "[Author Name]" }
  }
}
```

### FAQ Sections — FAQPage
```json
{
  "@context": "https://schema.org",
  "@type": "FAQPage",
  "mainEntity": [
    {
      "@type": "Question",
      "name": "[Question]",
      "acceptedAnswer": { "@type": "Answer", "text": "[Answer]" }
    }
  ]
}
```
